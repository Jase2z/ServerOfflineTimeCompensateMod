Use script-runner along with onServerStarted and onServerShutdown to adjust world time in the login database.  wurmlogin.db>Servers table>WORLDTIME entry
Store earth time at shutdown and the WORLDTIME time stamp in modsupport.db.  modsupport.db>OfflineServerTimeCompensateMod table>RLTSHUTDOWN, WORLDTIME

onServerStarted
* verify mod's table exists in modsupport.db. if not, create it, AND don't do any time adjustments. Log all this as a non-breaking error.
* Using modsupport data to advace (it shouldn't regress) wurmlogin-WORLDTIME based on how much real life time as passed since the server was last shut down.


onServerShutdown
* verify mod's table exists in modsupport.db. if not, create it, and add current earth time and the WORLDTIME time stamp. Log all this as a non-breaking error.
* Add to modsupport.db>OfflineServerTimeCompensateMod table>RLTSHUTDOWN, WORLDTIME
